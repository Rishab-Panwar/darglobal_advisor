How it works

A grounded agent,
not a chatbot wrapper

The advisor answers from public Dar Global and Wasalt data that was scraped, cleaned and checked. Language models plan and write; every number, filter, comparison and calculation is computed in code, and every claim cites its source. The figures on this page come from the running server and from the latest test runs.

01 · The life of a question

Plan → act → answer

A validated JSON plan works with any instruction-following model, is easy to log, and falls back to plain search if it doesn't parse. The How I found this panel under every answer shows these steps for that question.

0

Voice (optional) Google Speech-to-Text · Chirp 3

The browser records 16 kHz WAV and stops on silence. The UI language plus Arabic are passed as language hints; brand names are boosted, then normalised in code (French heard "Dar Global" as "d'art global"). Silence never reaches a model: given silence, the fallback once invented a sentence.

1

Guardrails Code · before any model

Prompt-injection and prompt-extraction attempts in five languages get a fixed, localized reply (no model call, nothing to argue with). Phone numbers and emails are removed before any provider sees the message.

2

Plan LLM → JSON

The planner returns which tools to run with typed arguments, plus three follow-up suggestions in the user's language. The plan is validated against a whitelist; money like "2M" is parsed in code.

3

Act Deterministic tools

search_pagesHybrid BM25 + bge-small embeddings, fused with RRF
filter_listingsTyped filters + medians and price per m²
list_projects / get_projectPortfolio by country, city or brand; fuzzy lookup
compare2–4 projects or markets; best values marked by rule
rental_yieldMedian rent ÷ median price, with a confidence label
investment_calcMortgage, cash flow, net yield (incl. 5% RETT)
4

Answer LLM · streamed

Written only from the tool results, citing [n] sources, in the language the user picked. Scraped text is treated as data, never as instructions. No promised returns, no price predictions, no personal contact details, and fair-housing requests are declined.

5

Interface Vanilla JS · 5 languages

Photo cards for listings and projects, the interactive calculator, side-by-side comparisons, inline citations, follow-up chips and RTL Arabic. The comparison builder calls /api/compare directly: instant, no LLM quota.

02 · Models

A chain, not a single point of failure

Each (provider, model) pair is a candidate, tried in order. A candidate is skipped if it errors, returns nothing, or fails mid-stream; one that returns HTTP 429 is put on a two-minute cooldown so later requests skip it instantly; OpenRouter's daily free cap is recognised from its reply and parks every OpenRouter model until midnight UTC. Gemini on Vertex AI answers first; the free OpenRouter models are the backup.

04 · Decisions

What was decided, and why

Most of these came from measuring, not guessing. Where testing changed the design, it says so.

Numbers come from code, never from the model

Filters, medians, yields, mortgage maths and every comparison cell are computed in Python, and the browser uses the identical formula for the calculator's sliders. The model explains the numbers; it doesn't produce them.

Hybrid retrieval

BM25 wins on exact names (projects, districts), embeddings win on paraphrases, and Reciprocal Rank Fusion merges them without tuning score scales. Hybrid beats either alone on the labelled set (see below).

Yields from medians, not per-m² ratios

Rental listings often carry the plot size as their area, which made per-m² yields absurd. Thin samples are labelled low confidence and kept out of rankings.

a 3-rental sample briefly made Makkah villas look like an 11% yield

Comparisons judge like with like

Best values are marked only within the same property type, never from thin samples. Unknown names are reported as not found rather than fuzzy-matched to something else.

an apartment was being marked "cheaper" than villas

Data is checked, not just scraped

Implausible prices are flagged and excluded; a photo shared by several project pages is treated as a banner; specs read from prose are tagged and were checked against their source sentences.

one project showed another project's photo; a SAR 3,500 "plot" was the cheapest land

Two layers of guardrails

Code blocks what must never reach a model (injection, contact details); prompt rules handle judgement calls (no promised returns, fair housing, off-topic), measured by the eval.

the first fair-housing answer said "no data" instead of declining

06 · Limits

What it doesn't do

  • Listings are a sample. They come from the first result pages of each Wasalt city and category, not the full inventory, and the bot says so.
  • Asking prices, not transactions. Yields and medians describe what sellers and landlords ask, on the scrape date.
  • Dar Global publishes no prices. Those cells say "Price on request" rather than guessing.
  • The backup has a quota. The free OpenRouter models allow 50 requests per day; when Gemini is unavailable and that cap is reached, the app says the models are busy.
  • Not affiliated. An independent prototype built for an application; not an official channel or financial advice.
